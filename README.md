Tema

Sistema de gestão de um lava-jato. Ele controla clientes, veículos, serviços (lavagem simples e higienização detalhada) e ordens de serviço, que passam pelos estados Aguardando → Lavando → Concluído → Finalizada (ou Cancelada). O preço do serviço varia conforme o porte do veículo.

Nesta entrega, as classes feitas em Java no 3º bimestre foram passadas para Dart (pasta lib/models) e as ordens de serviço aparecem em uma lista na tela.
